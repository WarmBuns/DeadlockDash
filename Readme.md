# Deadlock Skills (Beta Release)

Gives all survivors a universal extra Dash skill they can use that doubles attack speed while dashing. Default keybind is V, but it is configurable! 

Survivors have 2 dashes by default with a 4 second cooldown. 

The mod should work on any survivor vanilla or modded, as long as they have a "Body" state machine. If you find a survivor it doesnt work on please contact Buns (username: scholar.google.com) on the RoR2 Modding Discord or file a issue on Github [here.]()
